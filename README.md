# Signatures of the Contributor Licence Agreement

This branch holds no software. It is where the CLA workflow of `main`
(`.github/workflows/cla.yml`) records who has accepted the
[Contributor Licence Agreement](https://github.com/Ekwo-ai/ekwo-os/blob/main/CLA.md),
one row per person, under `signatures/`. A new version of the agreement is a
new path, and everybody is asked again.

Nothing here is edited by hand.
