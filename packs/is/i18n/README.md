# Where each language's wording comes from

The pack's own files are written in Icelandic (`defaults.language: "is"`), the
language of every source this pack reads — the law, the regulations, the RSK
guide and the RSK 10.01 form itself all publish nothing in a second official
language. `pack.json` declares no further language: a declared language is a
promise `ekwo pack check` holds the pack to keeping in full, covering every
account, journal, tax, box, chart and statement line, and no verified English
wording exists yet for the accounts of a chart this pack wrote itself (the
Icelandic Annual Accounts Regulation, nr. 696/2019, carries no official
English translation the way an EU regulation would).

An English translation is a welcome follow-up contribution — Skatturinn's own
English page (`skatturinn.is/english/companies/value-added-tax/`) gives some
of the vocabulary for the tax and its boxes, but not for a chart of accounts
this pack invented, and completing every key a declared language commits to
is more than this pack's first version attempted.
