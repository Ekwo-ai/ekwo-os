# Translations of the Serbia pack

The pack's own files are written in Serbian (Latin script), `defaults.language: "sr"`.

- `en.json` — English, translated from the Serbian labels of `accounts.csv`, `taxes.json`, `tax_report.json`, `statements.json` and the legal mention of `pack.json`, by whoever wrote this pack. Not an official translation of any Serbian text: the accounts, tax codes and box names are Ekwo's own transcription, and this file is a second reading of that transcription rather than of the law itself.
